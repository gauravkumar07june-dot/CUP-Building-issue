WhatsApp site group: daily report

The chat is read only on this device. It is not uploaded or saved.
  1. In WhatsApp, open the site group, tap the group name (or the ⋮ menu), choose Export chat and then Without media.
  2. Save the file to your phone or computer, then upload it here. A .txt or .zip file both work.
  3. Pick the day. The report lists construction queries by package, flags the ones with no reply, and lets you raise any of them in the register.
